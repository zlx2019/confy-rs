# Fixtures

Sample configuration files shared by the integration tests and examples.

| File | Purpose |
|------|---------|
| `config.toml` / `config.yaml` / `config.json` | the same configuration in all three formats |
| `default.toml` + `override.json` | base + override pair for layered-merging tests |
| `invalid.toml` | intentionally broken syntax for error-path tests |
